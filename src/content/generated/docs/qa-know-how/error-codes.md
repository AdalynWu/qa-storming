## 使用方式
- 先以 Code 或 Backend Key 找到項目。
- 再確認產品、操作步驟、登入身分、版本與網路狀態。
- 記錄使用者實際看到的訊息、是否可恢復，以及重試後結果。
- issue 不得包含 Token、驗證碼、真實帳號、付款資料或未遮蔽個資。
## 分類
- 1xxx：客戶端輸入與驗證
- 2xxx：業務規則與額度
- 4xxx：權限、登入與 JWT
- 5xxx：資料與資源
- 6xxx：流量與速率限制
- 9xxx：系統任務與其他
