# 章節目標
理解個人檔案在不同角色視角下的權限差異，以及內容建立、更新、刪除與跨裝置管理的主要驗證路徑。
## 角色與觀看視角
Master Design File 將個人檔案拆成三種觀看視角：一般使用者看創作者、一般使用者看自己，以及創作者看自己。QA 應先固定登入身分與檔案擁有者，再驗證內容與操作權限，避免只用同一帳號覆蓋全部情境。

## 建立、更新與刪除創作
1. 從創作者自己的個人檔案找到建立入口，確認可選內容類型與必填資料。
2. 送出後確認處理中、成功或失敗狀態，且新內容只出現一次。
3. 重新開啟既有內容進行更新，確認儲存、取消與返回不會留下半套資料。
4. 刪除前辨識目標與影響，完成或失敗後同步檢查列表、詳情與公開檔案。
### 必要狀態
- 無內容、首次建立、載入中、部分載入與載入失敗都有可辨識呈現。
- 長標題、長說明、多媒體比例與大量內容不會破壞個人檔案排版。
- 連續點擊、網路延遲、重整與返回不造成重複建立或更新遺失。
- 沒有權限、內容不可用或已刪除時，不保留失效操作或可返回的舊內容。
## 管理個人檔案
個人檔案管理在 Master 中提供 Desktop、Tablet 與 Mobile 對照。欄位與可見範圍可能依一般使用者或創作者身分不同，但儲存結果應在自己的檔案與他人看到的公開檔案一致。
### 跨裝置檢查
- 欄位標籤、目前值、字數限制、錯誤原因與儲存結果在三種裝置都完整可讀。
- 鍵盤、圖片選擇或系統字級放大後，儲存與取消仍在可操作範圍內。
- 切換身分、裝置或分頁後重新載入，已儲存資料一致；未儲存變更不會默默套用。
- 公開與非公開資訊的邊界清楚，截圖與 issue 不包含真實個資或未公開內容。
