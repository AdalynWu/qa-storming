# Creator Hub 導覽
Creator Hub 是創作者登入 Moor 後的重要起點，集中顯示任務、收益摘要、直播引導與建立內容入口。測試時除了確認每張卡片可用，也要確認資料是否屬於目前帳號與正確期間。
## 首頁載入與入口
- 首次進入時應顯示明確載入狀態，完成後不留下骨架或重複卡片。
- 主播任務、收益資訊、直播引導與建立內容入口應依帳號資格正確顯示。
- 點擊卡片後應進入對應功能，返回時保留合理的頁面位置與狀態。
- 帳號沒有資料或尚未取得資格時，需有可理解的空狀態，不以錯誤畫面取代。
## 主播任務
1. 確認任務標題、期間、條件與進度顯示完整。
2. 完成符合條件的操作後，回到 Hub 檢查進度是否在合理時間更新。
3. 驗證未開始、進行中、已完成、已過期與不可參加等狀態。
4. 重複進入或重新整理後，不應重複領取或倒退進度。
## 收益與直播引導
- 收益摘要應標示期間與單位，並與數據分析或直播結果中的同範圍資料一致。
- 新帳號、零收益、資料延遲與載入失敗要有不同且明確的呈現。
- 直播引導應依目前是否正在直播、是否具備權限與裝置狀態提供正確下一步。
- 建立內容入口不可因快速連點而重複開啟頁面或建立多份內容。
## QA 高風險情境
- 登入狀態過期、網路中斷或切換帳號後，舊帳號資料不可殘留。
- 卡片內容更新時，數字、徽章與 CTA 狀態需一起更新。
- 長標題、多語系、較小螢幕與系統字體放大時，關鍵數字與按鈕不可被裁切。
- 從子頁返回、App 進入背景後恢復，以及重試流程都要維持可操作。
