# 其他功能導覽
這些功能分散在不同入口，容易因資格、裝置權限或跨頁狀態造成落差。QA 應先記錄測試帳號條件，再驗證入口、流程與返回路徑。
## 推薦計畫
- 入口應依帳號資格、地區或活動狀態正確顯示。
- 推薦碼或分享連結需確認產生、複製、分享、失效與重複使用情境。
- 不符合資格、活動結束或資料載入失敗時，提示不可洩漏其他帳號資訊。
- 從外部連結返回 App 後，應進入正確頁面且保留合理狀態。
## 通知設定
1. 檢查 App 內各類通知開關的預設值與保存結果。
2. 關閉系統通知權限後，確認 App 內狀態與引導文字。
3. 從系統設定返回 App，頁面需重新取得最新權限。
4. 多裝置或重新登入後，確認設定同步規則符合需求。
5. 收到通知時，點擊後應進入正確內容；失效內容需有安全替代頁。
## 跨模組輔助功能
- 從 Creator Hub、我的頁面或通知進入子功能後，返回路徑需符合使用者預期。
- 同一狀態在不同頁面出現時，名稱、數值與可操作性應一致。
- 登入過期、版本不支援或功能關閉時，應提供明確下一步。
- 深層連結、背景恢復與快速重複點擊不可建立重複頁面。
## 共通錯誤情境
- 無網路、逾時、服務不可用與權限不足要有可區分的訊息。
- 重試後需清除舊狀態，且不可重複執行高風險操作。
- 測試功能旗標切換後，入口、快取與導覽狀態應一起更新。
- 功能隱藏時，既有通知或舊連結不應導向空白頁。
